До первого подключения подтвердить ревизию/суффикс, driver, отсутствие другого владельца COM,
питание антенны и актуальную документацию FW. По руководству ArduSimple POWER+GPS — native USB;
никаких дополнительных UART или аппаратных переделок пользователь не заявлял.
Flow control выключен, RTS/DTR выставлены False до open, но переходные состояния драйвера
при открытии/закрытии без реальной платы не проверены.

MON-VER отсутствует — не угадывать модель. RAWX/SFRBX отсутствуют — статус not_observed,
не объявлять отсутствие поддержки и не включать сообщения автоматически. При необходимости
настройки — отдельный этап со снимком, согласованием и readback. Не тестировать безопасный
CLI реальными VALSET/RESET только ради получения ACK/NAK: эти ветви уже проверяются Mock.

Сравнение с u-center: открывать закрытый лог либо делать отдельный последовательный захват
с той же конфигурацией. Одновременно открывать тот же COM двумя программами нельзя.
u-center не требуется для штатной работы регистратора.

До научного допуска отдельно проверить реальные пары частот на одном спутнике, loss-of-lock,
RINEX 3.02/LLI/эфемериды и текущий gnss_tec/ROTI-ноутбук. X20P получает отдельные логи и
проверку всех дополнительных частот: успех F9P не считается подтверждением X20P.
