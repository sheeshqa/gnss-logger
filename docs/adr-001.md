# ADR-001: read-first и clean-room

Актуализация: в версии 0.2.0 добавлены общий engine, ReplaySource, SerialSource и MockReceiver.
Дефолт Serial по-прежнему пассивный. `--inspect` разрешает MON-VER и чтение трёх RAM-ключей
из явно разрешённого поднабора; все физические write проходят `ensure_read_only`.
VALSET/VALDEL/RESET и произвольные пакеты блокируются до обращения к Serial.write.
ACK чтения не завершает запрос; нужен соответствующий ответ. Mock использует виртуальные часы
и явно синтетические FWVER/измерения. Ротация Replay проверяется автономно; аппаратный допуск отсутствует.

Ниже — исходное решение 0.1.0 и исходная таблица рисков; ограничение «только MON-VER»
заменено описанным выше разрешённым поднабором чтения.

Статус: принято для текущего прототипа; эксплуатационный допуск не пройден.

Решение: собственный небольшой UBX-парсер по официальной спецификации; pySerial 3.5 для транспорта.
Один read-loop передаёт исходные байты диагностике и необязательному файлу.
По умолчанию никаких write; по флагу — один фиксированный MON-VER poll.
Не реализовывать команды настройки в диагностическом прототипе. Не копировать код u-center.
Конвертацию впоследствии делегировать проверенному отдельно поставляемому convbin.

Причина: необходимо сначала подтвердить конкретную плату, FW и наличие наблюдений.
Цена решения: выключенные сообщения нельзя включить, активный профиль пока неизвестен,
пассивная идентификация может отсутствовать. Это явно отражается в отчёте.

| Риск | Последствие | Мера / проверка допуска |
|---|---|---|
| Неизвестная модификация/FW | Ошибочная трактовка сигналов | MON-VER, профиль под FW, никаких автоматических изменений |
| RAWX/SFRBX отключены | Пустой научный лог | Статус not_observed; отдельное согласование настройки |
| RTS/DTR связаны с reset | Перезапуск платы | Проверить схему до open; False до открытия не исключает glitch драйвера |
| Недостаточная скорость UART | Пропуски/повреждения | Расчёт 8N1, USB, интервалы/checksum, длительный аппаратный тест |
| Плохая антенна/питание | Невалидная фаза и срывы | Проверить питание и диапазоны, C/N0, half-cycle, locktime |
| Смена недели/reset/leapS | Ошибка времени | Неделя+TOW, clockReset; UTC-конверсия отложена |
| Ошибки/неполнота convbin | Потеря сигналов/эфемерид | Зафиксировать сборку и лицензию; сравнить OBS/NAV на одном логе |
| USB отключён/тишина | Неполный сеанс | Ошибка/возраст последнего сообщения, новый сегмент при будущем reconnect |
| Диск заполнен/OneDrive sync | Ошибка записи или блокировка | Немедленный error; позже локальный spool и контроль места |
| Сбой ОС/питания | Повреждение файла/отчёта | Сейчас fsync; позже SQLite, recovery и отдельные сегменты |
| OAuth/сеть/квоты | Задержка доставки | Будущая устойчивая очередь, resumable и защищённые токены |
| Ошибочный перенос на X20P | Потеря частот/неверные ключи | Независимый адаптер и тестовые логи; сейчас unsupported/unvalidated |

GUI, облако, автонастройка и второй приёмник не входят в текущую итерацию.
