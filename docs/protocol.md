# Источники и границы протокола

Проверено 2026-10-21. Физического устройства нет. В предоставленном сохранённом логе
прочитаны MOD=ZED-F9P, FWVER=HPG 1.13, PROTVER=27.12. Это не свежий аппаратный запрос.
Базовый документ: [F9 HPG 1.51, UBXDOC-963802114-13124 R01, 08.11.2024](https://content.u-blox.com/sites/default/files/documents/u-blox-F9-HPG-1.51_InterfaceDescription_UBXDOC-963802114-13124.pdf), интерфейс 27.50.
После MON-VER нужен документ именно обнаруженной FW; базовая версия не доказывает совместимость устройства.

| Сообщение | Class/ID | Раздел | Использование сейчас |
|---|---|---|---|
| RXM-RAWX | 02/15 | 3.17.6, с.198–199 | v1, 16+32×numMeas |
| RXM-SFRBX | 02/13 | 3.17.9, с.201 | v2, 8+4×numWords |
| MON-VER | 0A/04 | 3.14.15, с.140–141 | чтение ответа; необязательный poll |
| ACK-ACK / NAK | 05/01, 05/00 | 3.9 | разбор цели ACK/NAK, корреляция запроса |
| CFG-VALGET | 06/8B | 3.10.24 | запрос v0 / ответ v1; read-only RAM subset |
| CFG-VALSET | 06/8A | 3.10.25 | запрещено в CLI |

Справочные ключи F9P (CLI `--inspect` читает только RATE-MEAS и USB RAWX/SFRBX):

| Ключ | ID |
|---|---|
| RATE-MEAS / NAV | 30210001 / 30210002 |
| MSGOUT-UBX_RXM_RAWX UART1/UART2/USB | 209102A5 / 209102A6 / 209102A7 |
| MSGOUT-UBX_RXM_SFRBX UART1/UART2/USB | 20910232 / 20910233 / 20910234 |

RAWX несёт receiver-local week/TOW, leapS и признаки валидности. UTC из TOW напрямую не выводится.
Идентификаторы сигналов сохраняются численно, без переноса таблиц между прошивками.
MON-VER poll: `B5 62 0A 04 00 00 0E 34`. В логах может присутствовать вместе с ответом.
VALGET v0 содержит список ключей; v1 — пары ключ/значение. Нулевой MON-VER не является
повреждённым ответом. ACK на запрос чтения не заменяет ожидаемые данные.

X20PAdapter использует независимо сверенный поднабор из
[официального JSON HPG 2.02](https://raw.githubusercontent.com/u-blox/u-blox-X20-interface-description-json/main/HPG/u-blox-X20-HPG-2.02.json):
configuration/RATE/MEAS, MSGOUT/UBX_RXM_RAWX_USB, MSGOUT/UBX_RXM_SFRBX_USB.
Их ID совпадают с указанными выше; карты адаптеров раздельные.
RAWX-DATA1: payload version по offset 13 равен 1, 16+32×numMeas. Внутренний JSON versionId=2
не является значением поля payload version. SFRBX-DATA2: payload version 2.
Другие ключи/сигналы X20P не заимствуются; аппаратная проверка NOT TESTED.

Точный архивный интерфейс для HPG 1.13 / 27.12 — UBX-18010854 R08; полный документ с
официального хоста в этой итерации получить не удалось. Таблица F9 HPG 1.51 остаётся
справочной базой, не доказательством полной совместимости FW 1.13. Реальный лог подтверждает
декодируемый формат и сохранённые значения поднабора. Перед аппаратной конфигурацией
обязателен документ именно установленной FW. Никаких изменений конфигурации сейчас нет.

Поведение транспорта: [pySerial 3.5 API](https://pyserial.readthedocs.io/en/latest/pyserial_api.html).
Открытие может сопровождаться переходными состояниями RTS/DTR; исключить электрические побочные эффекты
можно только после проверки конкретной платы.
