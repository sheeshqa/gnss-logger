# GNSS Logger: руководство пользователя Windows

Приложение записывает поток u-blox UBX и конвертирует завершённые записи в RINEX.
Четыре раздела слева: «Запись», «Конвертация», «История», «Настройки».
Переключаться между ними можно мышью или стрелками после фокусировки списка;
Tab переводит фокус между элементами формы. При небольшом окне используйте
полосы прокрутки. Масштаб интерфейса задаётся средствами Windows.

## Запуск

Запустите GUI из установленного приложения либо portable-каталога. В portable
сохраняйте весь каталог поставки вместе: одного EXE недостаточно. Каталог
программы и каталоги измерений можно хранить отдельно.

Для запуска из исходников в подготовленной GUI-среде:

```powershell
python -m gnss_logger.gui
```

Демонстрационный режим включается аргументом `--mock`. В нём работают
синтетические приёмник и конвертер; COM-порты и внешний convbin не используются.
Результаты MOCK не являются измерениями или эфемеридами. Для повторного запуска
с теми же демонстрационными настройками задайте один и тот же абсолютный
`--mock-root`, расположенный строго внутри `%TEMP%/GNSS-GUI-MOCK`.
Windows может удалить временные данные; реальные измерения там не храните.

## Запись

1. Подключите приёмник, обновите список портов и выберите устройство и скорость.
2. Определите приёмник. После изменения порта или скорости повторите определение.
   Предыдущий успешный запуск программы не подтверждает текущее подключение.
3. Укажите каталог UBX, станцию, ожидаемую частоту и продолжительность либо
   ручную остановку. При необходимости включите суточную проекцию.
4. Запустите запись. Наблюдайте состояние, счётчики, предупреждения и журнал.
   Завершите кнопкой остановки и дождитесь итогового отчёта.

Автоконвертация требует подготовки до старта записи, включённой суточной
проекции и действительного профиля конвертера. Переключение Auto во время
записи управляет подготовленной очередью; оно не заменяет первоначальную
настройку. Отмена Auto и отмена ручной конвертации — отдельные действия.
Изменение значений по умолчанию не меняет параметры уже запущенной записи.

## Конвертация и внешний convbin

Для реальной конвертации требуется совместимый внешний `convbin.exe`.
Укажите его существующий путь в форме или загрузите подготовленный TOML.
Наличие GUI само по себе не подтверждает наличие или совместимость конвертера;
проверяйте диагностику запуска и итоговый отчёт. MOCK использует встроенную
имитацию и не проверяет работоспособность вашего внешнего convbin.

Выберите завершённый UBX, каталог либо сессию, настройте выходной каталог,
системы, сигналы, наблюдения и таймаут. Активный источник записи использовать
нельзя. Запустите конвертацию и дождитесь итогового статуса. Результаты ручной
и автоматической конвертации могут относиться к одному источнику: проверяйте
операции и пути в отчётах.

RINEX в текущей форме — 3.02. Опция «Разрешить OBS без NAV» допускает неполный
результат `OBS_ONLY_INCOMPLETE_NAVIGATION`: OBS опубликован, навигационных
данных недостаточно. Такой результат нельзя считать полным успехом OBS+NAV.
Предупреждения, ошибки и опубликованные файлы показаны отдельно.

«Отменить ручную конвертацию» запрашивает остановку текущей ручной операции.
Дождитесь конечного статуса. Уже опубликованные файлы сохраняются.
Открывайте каталог и отчёт соответствующими кнопками после завершения.

## Настройки и TOML

GUI хранит значения по умолчанию, корни истории, выбранный раздел и геометрию
окна в `%LOCALAPPDATA%/GNSS/config/gui-preferences.json`. Показанный на странице
«Настройки» путь является фактическим путём текущего экземпляра. В MOCK он
находится внутри выбранного временного корня. CLI не использует GUI preferences.

«Применить» изменяет значения для следующих операций в текущем окне.
«Сохранить» записывает настройки на диск. «Загрузить» повторно читает сохранённые
значения. Восстановление значений по умолчанию сначала меняет форму: примените
или сохраните их явно. После перезапуска запись сама не запускается,
а приёмник необходимо определить снова.

Профиль конвертации хранится отдельно в TOML. Загружайте и сохраняйте его
на странице «Конвертация»; путь профиля по умолчанию выбирается в «Настройках».
«Сохранить как…» создаёт отдельный профиль, сохраняя абсолютные пути.
При перезаписи TOML комментарии и исходное форматирование теряются; приложение
запрашивает подтверждение. Сначала сохраните изменённый TOML, затем GUI defaults.

При внешнем изменении файла возможен конфликт: перечитайте файл и повторите
свои изменения. Повреждённые preferences не перезаписываются автоматически;
явное восстановление сохраняет исходные байты в резервной копии. Сообщение
о занятом файле или lock требует проверки другого экземпляра приложения;
не удаляйте защитные файлы работающего экземпляра.

## История и завершение работы

В «Настройках» добавьте каталоги истории по одному пути на строку, затем
примените или сохраните. «История» читает только настроенные корни и результаты
текущего окна. Поиск сужает список; выбор строки загружает подробности.
Сохранённая оценка целостности — результат прежней записи, а не новая проверка
всех байтов UBX. «Нет данных» означает отсутствие сохранённой метрики.
История не удаляет и не исправляет архивы.

При закрытии с изменённым TOML выберите сохранение, отказ от изменений или
отмену выхода. При активной операции отдельный диалог предлагает остановить
запись и отменить ручную конвертацию либо дождаться её; Auto-очередь завершается
перед выходом. Дождитесь закрытия окна, чтобы фоновые задачи закончили работу.

## Проверка интерфейса без оборудования

Разработческий [native smoke](../tests/stage45cd_native_smoke.py) запускается
вручную после согласования тестового окна. Он проверяет исходники и, при
передаче `--exe`, собранный GUI в отдельных процессах при масштабе 100/125/150%,
затем повторно запускает каждый вариант с сохранёнными настройками.
JSON-отчёты и снимки реальных виджетов сохраняются в новый каталог `--output`.
Эта проверка не заменяет испытания приёмника, внешнего convbin или установщика.
